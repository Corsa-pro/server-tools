Go to **Settings > General Settings > Companies** and choose the **Icon
Style**: Outlined (the default, as in Odoo 20), Rounded or Sharp. The style
is the company's: with several companies, each can have its own, and the
backend draws the icons in the style of the active company.

To give a website another style, install `website_material_symbols` (it
installs itself with Website) and set it under **Website > Configuration >
Settings**.
